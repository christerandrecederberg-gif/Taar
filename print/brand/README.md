# Tår designprofil

Hentet fra logofilene og designerens trykksaker (meny, gatebukk, dørfolier).

## Farger
| Navn | Hex | Brukes til |
|---|---|---|
| Tår-blå | `#2C428B` | Logo, overskrifter, tabellhode |
| Taupe | `#8A8070` | «KRISTIANSAND» / «COCKTAILS & KAFFE», småtekst |
| Krem | `#F7F4EF` | Lys logo, bakgrunnsflater (skilt bruker også `#EDE7DB`) |
| Lys blå | `#DDE2EE` | Rolige flater, seksjonslinjer |

## Skrift
- **Spectral** (serif, gjerne kursiv): menyer, undertitler, «TÅR /tɔːr/ — a sip».
- **Inter** (sans, fet og versaler med sperring): taglines og etiketter.
- Cormorant Garamond brukes i enkelte skilt.
Alle finnes gratis på Google Fonts; kopier ligger i `fonts/`.
